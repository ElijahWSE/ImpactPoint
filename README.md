# Impact Point first draft

Open index.html in a browser. The folder is a standalone static website, suitable for the root of a GitHub Pages repository. All imagery is local and paths work under a repository subdirectory.

Edit text and links in index.html. Each homepage section has a descriptive id and can be moved with its entire section block. Update colours in the :root variables in style.css. Replace photographs in assets or change their filenames in the HTML.

Events are maintained manually. When adding a date, replace the upcoming-workshop message with its date, title and registration link. Move completed events into the past workshops list.

The story, event listings, workshop details, platform directory, AQADAY overviews and contact page are local HTML pages. Contact and quote buttons open the current Squarespace forms. The privacy notice is included locally. AQADAY login uses its existing destination. Update form and policy links before moving the live domain. Update both events.html and the homepage when workshop listings change.

The globe uses public-domain Natural Earth 1:110m land outlines. The static first frame faces Southeast Asia. The map in assets/world-map.js is embedded for direct offline previews. The lettering completes an idle orbit in four minutes. One screen of scrolling adds a fifth of a turn. Hovering over the globe brings up a soft highlight and a five-second breathing cycle. The pause control freezes automatic motion, and reduced-motion mode shows a still composition.
